# Mesana — Descargas oficiales

**Mesana** es un punto de venta para restaurantes, loncherías y fondas: toma pedidos con variantes, combos a elegir, comandas a cocina, cobro con efectivo, tarjeta, transferencia, Uber Eats y DiDi, reportes y respaldos automáticos. Funciona sin internet.

Este repositorio solo contiene los **instaladores oficiales**. Mesana instalada revisa aquí si hay versiones nuevas y se actualiza sola.

## Descargar

1. Entra a **[Releases → la más reciente](https://github.com/jesusivangd11/mesana-releases/releases/latest)**.
2. Descarga `Mesana-Setup-X.X.X.exe` (en *Assets*).
3. Ábrelo. Si Windows muestra “Windows protegió su PC”, da clic en **Más información → Ejecutar de todas formas**. Solo pasa la primera vez.

**Requisitos:** Windows 10 u 11 de 64 bits. No necesita permisos de administrador.

## Prueba y licencia

Mesana funciona completa **30 días gratis**. Después se activa con una clave de licencia. Tus datos se conservan siempre: se guardan en tu computadora (`%LOCALAPPDATA%\Mesana`), no en internet.

## Actualizaciones

No tienes que hacer nada: Mesana busca versiones nuevas cada pocas horas, las descarga en segundo plano y te avisa para reiniciar. Antes de instalar hace un respaldo.
