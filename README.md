# FoodPoint — Descargas oficiales

**FoodPoint** (antes **Mesana**) es un punto de venta para restaurantes, loncherías y fondas: pedidos con variantes, combos a elegir, comandas impresas en cocina y monitor de cocina, cobro con efectivo, tarjeta, transferencia, Uber Eats y DiDi, reportes y respaldos automáticos. Funciona sin internet.

> **¿Tenías Mesana?** Es el mismo sistema con nombre y logo nuevos. Se actualiza solo y conserva tus ventas, productos, configuración y licencia.

Este repositorio solo contiene los **instaladores oficiales**. FoodPoint revisa aquí si hay versiones nuevas y se actualiza solo.

## Descargar

1. Entra a **[Releases → la más reciente](https://github.com/jesusivangd11/mesana-releases/releases/latest)**.
2. Descarga `FoodPoint-Setup-X.X.X.exe` (en *Assets*).
3. Ábrelo. Si Windows muestra “Windows protegió su PC”, da clic en **Más información → Ejecutar de todas formas**. Solo pasa la primera vez.

**Requisitos:** Windows 10 u 11 de 64 bits. No necesita permisos de administrador.

## Prueba y licencia

FoodPoint funciona completo **30 días gratis**. Después se activa con una clave de licencia. Tus datos se guardan siempre en tu computadora, no en internet.

## Actualizaciones

No tienes que hacer nada: FoodPoint busca versiones nuevas cada pocas horas, las descarga en segundo plano y te avisa para reiniciar. Antes de instalar hace un respaldo.
